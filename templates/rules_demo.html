🏛️ Rule Placement Strategy: Python Application Layer vs MySQL DBMS Constraints

Rule / Requirement Enforced Layer Mechanism & Implementation Technical Rationale
Referential Integrity MySQL DBMS Foreign Keys: ON DELETE RESTRICT / CASCADE Guarantees relational consistency across sessions regardless of client.
Entity Uniqueness (EPIC, Codes) MySQL DBMS Unique Constraints & B-Tree Indexes (UNIQUE(epic_number)) Database-level atomic prevention of race conditions during concurrent inserts.
Audit Trail Logging Hybrid: MySQL Trigger + Python trg_voter_status_update + StatusHistory inserts Trigger guarantees immutable audit log on direct SQL updates; Python captures officer remarks.
18-Year Age Eligibility Python Application Dynamic lookup of active qualifying_date in calculate_age_on_date Allows varying qualifying dates across different election cycles without schema alteration.
Exact-Match Duplicate Detection Python Application Normalized multi-column lookup + DuplicateAudit logging Enables custom case-insensitive trimming, phonetic pre-matching, and audit tracking.
1,200 Booth Capacity Limit Python Application Transactional COUNT(*) check before booth assignment Provides dynamic re-routing of voters to auxiliary polling stations and friendly UI feedback.
15-Day Appeal Window Python Application Statutory date difference comparison against rejection notice Delivers granular error messaging explaining exact elapsed days vs statutory threshold.
